✅ Step-by-step understanding (NO memorization)
Code:
int x = 5;
int y = x++;
int z = ++x;
Console.WriteLine($"{x}, {y}, {z}");

🔹 Line 1
int x = 5;


➡️ x = 5

🔹 Line 2 (POST-increment)
int y = x++;


Rule:

x++ → use first, then increment

Assign current x to y → y = 5

Increment x → x = 6

✔️ Now:

x = 6
y = 5

🔹 Line 3 (PRE-increment)
int z = ++x;


Rule:

++x → increment first, then use

Increment x → x = 7

Assign to z → z = 7

✔️ Final values:

x = 7
y = 5
z = 7

✅ Output
7, 5, 7

🧠 ONE Golden Rule (never forget)
POST (++ after) → use → then change
PRE  (++ before) → change → then use

✅ Answers & Explanation
✔️ MCQ 1
int a = 10;
int b = a++ + ++a;


Step:

a++ → use 10, then a=11

++a → a=12, use 12

b = 10 + 12 = 22
a = 12


✅ Output:

12, 22

✔️ MCQ 2
x++ + x++ + ++x


Step:

x++ → 1 (x=2)

x++ → 2 (x=3)

++x → 4

Result = 1 + 2 + 4 = 7
x = 4

✔️ MCQ 3
i = i++ + i++;


Step:

First i++ → 5 (i=6)

Second i++ → 6 (i=7)

i = 5 + 6 = 11

✔️ MCQ 4
a++ * ++a


Step:

a++ → 3 (a=4)

++a → 5

b = 3 * 5 = 15
a = 5

✔️ MCQ 5 (KILLER)
x = x++;


Step:

x++ returns old value → 5

then increments → 6

assignment overrides increment

❗ Final:

x = 5

🧠 Level-3: Method call side-effects
❓ Q5

{
    return x++ + ++x;
}

int a = 5;

Console.WriteLine($"{a}, {b}");

🧠 Level-4: Loop trap (INTERVIEW FAVORITE)
❓ Q6

{
    Console.Write(i + " ");
}

❓ Q7

}

🧠 Level-5: Logical + increment (VERY nasty)
❓ Q8
int x = 1;
if (x++ > 1 && ++x > 2)
{
    Console.WriteLine(x);
}
else
{
    Console.WriteLine(x);
}
